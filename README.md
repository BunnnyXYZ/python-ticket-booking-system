# python-ticket-booking-system
console-based ticket booking system built using python and CSV file handling for persistent data storage.

## 🌟 Key Features
* **Seat Reservation:** Book available seats dynamically.
* **User selection:** The user can see status of all seats and select the one they like.
* **Basic details:** When seat status is displayed it is also displayed if the seat is window or aisle.
* **print ticket:** Simply enter your ticket id shown at time of booking to get the full ticket with details printed in terminal.
* **Ticket Cancellation:** Cancel bookings and free up seats.
* **Real-time Availability:** Check seat status updated directly from the storage file.
* **Data Persistence:** Uses CSV file read/write operations to save reservation state even after closing the app.

## 🛠️ Built With
* **Python 3**
* **CSV Module** (Standard Library)
